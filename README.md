# 🌍 WeatherGuru Gold — Overview & Features

A modern, fast, multi-language weather application with real-time GPS location tracking, coastal/marine safety advisories, transit delay risk alerts, 50-language support, and audio voice weather reports.

### ✨ Key Features
- **📍 Auto GPS & Geolocation:** Instant detection of current city, division, and region worldwide.
- **🔊 Live Audio Voice Weather Forecast (TTS):** Clear Bangla and English spoken weather reports.
- **⚠️ Early Warning Disaster Advisories:** Cyclones, heatwaves, heavy downpours, river surges, and lightning risks.
- **🗺️ Interactive Meteorological Radar Map:** Real-time clouds, precipitation, wind streams, and temperature heatmaps.
- **🌐 50+ Languages:** Seamless one-tap language switching with instant localization.
- **📱 True Multiplatform:** Android APK, Google Play Store AAB, and Apple iPhone iOS Support.
